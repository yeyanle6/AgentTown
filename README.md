## 工作闭环

发现 → 自主选择/等待 → 接单与计划 → 可选预算内委托 → 执行 → 保存交付物与 SHA-256 → 独立验证 → 结算 → 保存已验证技能。

预算内来源委托会依据父任务选择行情或 PyPI/GitHub 来源，核查结果再次由独立规则验证；来源委托不能脱离父任务单独申请公共预算。

员工提案必须使用当前能力模板的准确交付与验收合同，并明确预算、截止条件及本次目标。额外要求或不一致合同会被拒绝，不冻结公共资金；审批原文与理由可在任务市场查看。

“独立验收”是明确的客观验证程序，验收报告显示全部输入、预期、实际结果与验收身份；不是声称有独立人类评审。平台拒绝自我验收、无证据发奖、重复付款和超预算支出。不是通用联网电脑代理：用户任务目前采用已有客观验收契约的模板，任意额外要求不会自动验收付款。

## 数据真实性

来源为 Coinbase Exchange 公共 ticker、Kraken 公共 ticker、PyPI JSON 与 pandas 官方 GitHub Releases API。每次采集记录 URL、来源发生时间（可以缺失）、获取时间、状态、提取内容与内容指纹。Kraken ticker 不提供成交发生时间，因此标记为未知。PyPI/GitHub 发布时间是历史事件，但本次真实获取，并非历史回放。源站连接失败时记录缺失，不用合成数据补齐。早期快照的 `retrieved_at` 记录请求发起时刻，查看器明确使用这个标签；后续采集记录请求完成时刻并在提取内容的 `_agenttown.retrieved_at_basis` 中标记。旧快照保持原样，不追写或伪造历史时间。所有历史来源快照按编号同步到云端归档；交付物内可打开当时引用的提取内容、时间和 SHA-256，避免旧报告只能核对源站的当前数据。

模拟成交采用新鲜真实行情的最后成交价格，单笔配置最多当时净值的 20%，假设单边费用 10bps，不模拟滑点和市场冲击，不使用杠杆。收益仅描述虚拟实验表现。

## 运行与维护

```sh
# 项目根目录
npm ci
npm run dev                # 本地控制台
python3 -m engine.main     # 前台运行；已有服务时单实例锁会拒绝重复启动
python3 -m unittest discover -s tests -v
npx tsc --noEmit
npm run build
```

后台服务安装：`python3 scripts/install-service.py`。它将执行代码复制到 `~/Library/Application Support/AgentTown`，避免 macOS 后台进程访问 Documents 的权限阻塞；项目中的 `.runtime` 是该服务状态目录的符号链接。更新代码时先 `launchctl bootout gui/$(id -u)/com.agenttown.community`，再运行安装脚本，状态不会被覆盖。

- 服务标识：`com.agenttown.community`
- 健康检查：`http://127.0.0.1:8766/api/health`
- 状态：`.runtime/community.sqlite3` 与 `.runtime/snapshot.json`
- 日志：`.runtime/engine.log`、`.runtime/engine-error.log`
- 模型请求与返回：`.runtime/brain/`（仅本地，禁止提交）
- 私有云连接配置：`.runtime/cloud.json`，权限 0600，不提交源代码。
- SQLite 是执行状态的唯一事实来源；D1 是持久云端镜像和干预收件箱。云端干预在执行器确认前显示“排队”，不是成功假象。

云端不直接持有 Codex 登录凭据。同步使用仅发往本私有站点的平台服务令牌，以及独立应用同步密钥。所有生成源码仅在限制导入、私有属性、反射与危险内置函数的执行器中处理，并有 CPU 与父进程超时限制。此为可信本地实验环境，不能视为面向不受信任多租户的完整 OS 容器隔离。

## 项目结构

- `engine/store.py`：持久状态、事务、冻结预算、独立结算、审计重放。
- `engine/sources.py`：真实来源采集、时间与缺失校验。
- `engine/brain.py`：结构化模型决策、代码生成调用、超时与停止。
- `engine/skills.py`：投资、研究、开发、独立验收工具。
- `engine/main.py`：调度、委托、提案规则、恢复、截止守卫、同步和本地 API。
- `components/community.tsx`：社区总览、任务、项目、员工、账户、技能、动态和来源。
- `app/api/`：私有云读写、幂等命令队列与同步。
- `db/schema.ts` / `drizzle/`：D1 结构与不可变迁移。
- `tests/test_engine.py`：奖励依据、重复支付、篡改、预算、委托取消、源时间、订单恢复及受限代码测试。

恢复依赖真实模型账号和网络。不得把测试夹具导入当前真实数据模式数据库；测试使用临时隔离数据库。
